# SHIFTCREATIVE × TezPi house voice

The tell library says what to strip. This file says what to pull toward when no client reference or brand DESIGN.md is given. A project reference or DESIGN.md overrides it. If `review_due` has passed, mention it in the notes so it gets refreshed.

## Principles

1. **Motion has a job or it doesn't exist.** Every move guides attention, gives feedback, or carries feeling. Decoration is cut.
2. **Premium means restraint plus precision.** Fluid, native-feeling curves; exact timing; generous negative space; sharp typography. Effects are rare and earned.
3. **Minimal, but it should still move someone.** Fewer elements, each one specific, with one beat that is allowed to be felt.
4. **The viewer's journey decides the cut.** Like a product flow: lower the cognitive load, show the next step before it is needed, put the call to action where the attention already is.
5. **Built like a system.** Tokens, roles and variants rather than one-off tweaks, so a change in one place stays consistent everywhere.
6. **Rule of Six first.** Emotion, then story, then rhythm, before eye-trace and the screen planes.

## Audience routing

| Surface | Pull toward |
|---|---|
| Competition jury, pitch | Clarity of the one idea, confident holds, evidence on screen, calm sound |
| Vietnamese social (TikTok, Facebook, Zalo) | Specific hook in frame 1, natural Vietnamese copy (no translated-slogan tone), captions chunked by meaning |
| Product / SaaS (Agent-X, sales AI) | Real UI and real flows, data that reads and is believed, micro-interaction physics consistent with the product |
| Game UI / HUD, Discord community | Energy and punch are allowed; still one focal point per moment and readable type |
| Luxury, real estate | Time, light and silence; symmetry and slow arcs by intent |

## Anti-examples (sounds or looks like us? rewrite it)

| Not this | This |
|---|---|
| Logo sting with particles before anything happens | Open on the product doing its job; logo at the end |
| "Nâng tầm trải nghiệm khách hàng" | What the customer gets, in their words, with the number |
| Every card fades up with the same stagger | Hero first on its own curve, support follows by role |
| A whoosh on every transition | Straight cuts; one sound where the story turns |
| Glow on the CTA to make it important | The CTA is important because it is the only thing moving |
